# ルートヒストリー：年の追加方法

普段は `index.html` をブラウザーで開いてください。2024年・2025年を切り替えられ、旅行別のページを開いても画面上部の年選択は残ります。「年間地図に戻る」で選択中の年の全体表示に戻れます。

初回は公開済みの最新年を表示します。同じタブでは最後に選択した年を記憶します。`index.html#year=2024` のように表示年を指定することもできます。地図背景にはネット接続が必要です。

## 2026年を追加するとき

1. 2026年のGPXから、2024・2025年と同様の集計と年別HTMLを作成します。年一覧への登録だけではGPXの解析は行いません。元データと編集版の重複、日付をまたぐ記録、旅行期間、道路・線路データの範囲を確認してください。
2. このフォルダー内に `2026` フォルダーを作り、年間ページを `2026/2026-route-history.html` に保存します。旅行別ページと集計レポートも同じフォルダーに置き、年間ページからのリンクを相対パスにします。
3. `years.js` の2026年の行を次のように変更します。

```javascript
{ year: 2026, status: 'ready', page: '2026/2026-route-history.html', report: '2026/2026-summary.md' }
```

4. `index.html` を再読み込みすると2026年を選択できます。2027年以降も同じ形式で行を追加します。入口ページのHTMLは変更不要です。

年別ページは独立したHTMLのため、年ごとの地図・集計処理を更新しても他の年には影響しません。入口ページは同時に1年分だけを読み込みます。

## 保存するファイル

`index.html`、`years.js`、既存の年間ページ・旅行別ページ、年別フォルダーを一緒に保管してください。フォルダー構成を保ったままコピーすれば利用できます。2025年のファイルは既存リンクを維持するため、このフォルダー直下に残しています。
